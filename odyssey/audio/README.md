# Audio for the Odyssey chart

Put recordings here and list them in `../index.html` (window.AUDIO_CONFIG). Moods the chart reports: calm, lonely, tense, grief, home.

Suggested sources:
- Lina Palera, "Seikilos Epitaph with the Lyre of Apollo" (14:51, real lyre) — CC BY-NC-SA 3.0, non-commercial use only:
  https://freemusicarchive.org/music/The_Music_of_Ancient_Greece/An_Appreciation  → save as palera-seikilos-lyre.mp3
- Scott Buckley, cinematic orchestral library — CC BY 4.0 (credit him in the config's "by" field, which is shown on the page):
  https://www.scottbuckley.com.au/library/mood/emotional/  and  https://www.scottbuckley.com.au/library/mood/epic/
  Solo cello and string pieces suit "lonely" and "grief"; slow-burn orchestral builds suit "tense".
- Sea ambience: a CC0 waves loop from freesound.org, listed under sfx.ambience.
